## 当前未完成问题

下一阶段继续解决：

机器人 pelvis / base_link 长时间倾斜。

已经确认：

V1.5 root tilt:
mean ≈ 9.55 deg
max ≈ 26.70 deg

GMR pelvis target:
mean tilt ≈ 10.36 deg

在部分帧实际 root 与 GMR target 差异很大。

例如：

frame 407:
target tilt ≈ 8.26 deg
robot tilt ≈ 26.70 deg

frame 422:
target tilt ≈ 3.63 deg
robot tilt ≈ 21.82 deg

RootLock 40/40 实验已经证明：
单纯提高 base_link orientation weight 不是正确最终方案，
会造成腿脚几何和 waist pitch 明显恶化。

因此 RootLock V1 仅作为实验，不作为稳定基线。

## 2080 Ti 开始工作前

先确认：

python --version

python -c "
import torch
print(torch.__version__)
print(torch.version.cuda)
print(torch.cuda.is_available())
print(torch.cuda.get_device_name(0))
"

python -c "
import mujoco
print(mujoco.__version__)
"

随后先播放 V1.5：

python tools/linglong/view_linglong20_qpos37.py \
  --csv \
  output/linglong20_arm_v15_strong_extension/linglong20_arm_v15_strong_extension_qpos37.csv \
  --speed 0.5

确认播放完全一致以后，
再继续 pelvis / root upright 修复。
